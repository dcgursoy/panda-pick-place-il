# Milestone 4: splits, statistics, LeRobot export and cross-check

Date: 2026-10-31 (overnight run, continued). Driver 32.0.101.9150, XPU trusted.

## What was built

- `panda_il/data/splits.py`, `stats.py`, `dataset.py` (window dataset) and `export_lerobot.py` were written during milestone 3 while the scripted recording ran; this milestone exercised them on `scripted_v1` and added the cross-check.
- `tools/lerobot_env/crosscheck_dataset.py` (LeRobot environment): opens an export with `LeRobotDataset`, compares 200 random frames with our Zarr, builds a `To = 2`, `Tp = 16` window through LeRobot's `delta_timestamps`, and lists the features `dataset_to_policy_features` would hand a policy. One import had moved in LeRobot 0.6.1 (`lerobot.utils.feature_utils`); fixed here.
- DESIGN.md section 13 records the window alignment (chunk starts at the current observation, executed slice `[0:Ta]`), the split and subset rules, and what the cross-check does and does not cover.

## What failed first and how it was fixed

- `from lerobot.datasets.utils import dataset_to_policy_features` no longer exists in 0.6.1; the function lives in `lerobot.utils.feature_utils`.
- The first export run was a 3-episode smoke export into the same directory; LeRobot refuses to create a dataset over an existing one, so the full export deletes the smoke output first (the command above assumes an empty target).
